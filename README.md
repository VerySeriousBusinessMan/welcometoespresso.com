# Welcome to Espresso

Static homepage for welcometoespresso.com, hosted on GitHub Pages.

## Files
- `index.html` — the homepage (GitHub Pages serves this automatically)
- `images/` — site photos (see DOWNLOAD-THESE-IMAGES.txt — you must add 4 image files here)
- `CNAME` — tells GitHub Pages to use the custom domain welcometoespresso.com
- `.nojekyll` — tells GitHub Pages to serve files as-is (skip Jekyll processing)

## To publish
1. Add the 4 image files to /images (see DOWNLOAD-THESE-IMAGES.txt)
2. Commit ALL of these files to the ROOT of your repo (not in a subfolder)
3. Repo Settings > Pages > Source: "Deploy from a branch", branch: main, folder: / (root)
4. Wait for the green "Your site is live" message
5. Test the github.io URL first, then welcometoespresso.com
